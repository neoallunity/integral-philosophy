# 🧠 Integral Philosophy — Monorepo

Консолидация 8 модулей платформы академического издательства в единый репозиторий
(история сохранена через `git subtree`).

## Структура

```
modules/
├── core/      # движок обработки контента (Python)
├── web/       # веб-интерфейс и API
├── cli/       # CLI-инструменты
├── docs/      # документация
├── content/   # примеры контента и датасеты
├── config/    # конфигурация и правила обработки
├── deploy/    # инфраструктура и деплой
└── tests/     # тестовый комплект
```

## CI

GitHub Actions matrix: линт+тесты по каждому модулю + интеграционный прогон.
Исходные модульные репозитории остаются read-only для ссылок; канонический код — здесь.
